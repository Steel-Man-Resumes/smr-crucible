# Security Policy

This platform handles sensitive information for a vulnerable population. We take
security and privacy seriously.

## Reporting a vulnerability

Please report security issues privately. **Do not open a public GitHub issue.**

Email **security@steelmanresumes.com** with:

- a description of the issue and its impact,
- steps to reproduce, and
- any relevant logs or proof of concept (no real user data, please).

We will acknowledge within a few business days and keep you updated as we work on a
fix. We are grateful for responsible disclosure and will credit reporters who wish to
be named once an issue is resolved.

## Handling user data

If your report involves access to real user data, stop, do not download or retain it,
and tell us immediately so we can contain the exposure.

## Scope

In scope: the application code in this repository and the deployed Steel Man services
(steelmanresumes.com and subdomains). Out of scope: third-party providers (Vercel,
Neon, Cloudflare, Anthropic, OpenAI, Resend), which have their own disclosure programs.
