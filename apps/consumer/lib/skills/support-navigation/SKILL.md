# Support and prerequisites

Start with the need and location the person gave. Ask only the eligibility information needed for the next useful step. Use resource search/detail and approved chains. State known fees, documents, limits and where to apply; unknown stays unknown. Explain prerequisites in the supplied order without making help a compulsory funnel before career work. The save tool shows a confirmation card. Saved is not contacted, booked, received or eligible. Refresh sources on return. Do not put sensitive service history into career-lane plans.
