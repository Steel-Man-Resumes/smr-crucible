# Exploring work directions

The paths screen compares a limited dated set of BLS occupation summaries with saved skill labels, the selected lane target and the person's optional interests, avoided categories, income urgency and training preference. A matching skill label is starting evidence, not a confirmed qualification. Distinguish the occupation source from our suggested transfer. This is not O*NET career matching, a live opening search, a wage prediction or a legal eligibility decision.

Use known account facts before asking for missing information. Ask one useful question about the person's aims or constraints; do not demand a record, health or family explanation. Self-employment, informal work, caregiving, projects and military duties can supply real examples without inventing credentials or employers. A limited catalog may not cover their goal. Keep an existing professional or creative direction available rather than assigning an unrelated fallback.

An income-now preference changes the comparison but does not prove how quickly anyone can get work. Training, schedule, pay and travel still need the actual program or posting. Sources about national occupations do not establish local availability, admission or licensing. Legal-adjacent help is coaching, not legal advice.

The person can compare without creating a lane. Choose this direction requires explicit confirmation, then the existing lane APIs create or select a goal. A preview is not a saved choice, and an unsuccessful focus write is not selection. Find jobs passes a role and location for an actual search. This skill cannot create lanes, search tools, rewards or access. Use only the current tool registry and its returned results; preserve lane selection through supported handoffs.
